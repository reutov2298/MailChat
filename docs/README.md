## Статус документации
Эти документы описывают целевую архитектуру, а не утверждают, что она уже полностью реализована в текущем приложении.

Статусы решений: предложение, согласовано, реализовано, устарело.

Если целевая архитектура расходится с текущим кодом, расхождение фиксируется отдельно и включается в план миграции. AI-агенты обязаны различать утверждённые решения и предложения.

## Изменение документации
Существенные изменения обсуждаются и согласуются до реализации. Документация изменяется через отдельные ветки и Pull Request. Архитектурные изменения сопровождаются причиной, последствиями и статусом.
