# Кандидат UT: комментарии Drom.ru

**Статус:** исследуется с существенными ограничениями; адаптер не реализован.

## 1. Идея

Проверить комментарии к публичным объявлениям Drom.ru как потенциальную доску обмена: отправитель публикует зашифрованный текст в комментарии, второй клиент получает новые комментарии по странице объявления или через доступный интерфейс.

Официальная справка Drom подтверждает, что владелец объявления может использовать поле «Комментарий к объявлению» для дополнения текста и фотографий. Отдельная страница Drom показывает ответы на комментарии и указывает, что читать ответы могут только зарегистрированные пользователи.

Источники:
- https://baza.drom.ru/help/VozniklaProblema/ObjavlenijaIUslugi/RedaktirovanieObjavlenija
- https://www.drom.ru/misc/comments/
- https://baza.drom.ru/help/rules/

## 2. Доступ и API

На момент исследования не подтверждён официальный публичный API для произвольной публикации и чтения комментариев к объявлениям.

У Drom есть опубликованная документация API для отдельных операций с объявлениями и фотографиями. Это не доказывает наличие API комментариев. Нельзя переносить endpoint объявлений на комментарии или считать найденные неофициальные HTTP-запросы стабильным контрактом.

Необходимо выяснить:
- доступны ли комментарии к объявлению без входа;
- можно ли получить полный список комментариев и стабильные ID;
- есть ли официальный API чтения/создания/удаления комментариев;
- нужна ли авторизация и какие права/ограничения действуют;
- как быстро новый комментарий виден другому аккаунту;
- есть ли пагинация, сортировка, поиск новых записей и защита от пропусков.

## 3. Критическое ограничение правил

Правила Baza Drom содержат запрет на публикацию объявлений с использованием сторонних программно-технических средств, а также ограничения на рассылку сообщений лицам, не выражавшим желания их получать. Это не позволяет автоматически считать машинную публикацию комментариев разрешённой. До любого PoC с автоматизированной публикацией необходимо выяснить применимость правил и получить допустимый способ использования. Нельзя обходить CAPTCHA, антиспам или технические ограничения.

## 4. План исследования

1. Ручным способом проверить чтение комментариев без регистрации и с двумя тестовыми аккаунтами.
2. Установить, существует ли официальный поддерживаемый интерфейс для комментариев.
3. Проверить правила и получить разъяснение Drom по допустимости автоматизированного обмена.
4. Если официально разрешённый способ существует — провести двухклиентский PoC.
5. Измерить T_publish, T_visibility, T_discovery, T_download и T_e2e.
6. Проверить модерацию, ограничения аккаунта, редактирование, удаление, дубли и пропуски.
7. Отдельно проверить сетевую доступность в ограниченных сетях.

**Предварительный вывод:** Drom интересен как потенциальная публичная доска, но пока имеет низкую техническую определённость и заметный риск по правилам автоматизации. Не включать в список поддерживаемых транспортов без официально допустимого способа публикации и успешного теста.
