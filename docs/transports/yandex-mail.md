# Кандидат UT: Яндекс Почта

**Статус:** исследуется; адаптер не реализован, скорость и пригодность не измерены.

## 1. Доступные интерфейсы

У Яндекс Почты есть два релевантных интерфейса:

- **IMAP/SMTP с OAuth (XOAUTH2).** OAuth-приложение получает права на отправку через SMTP (`mail:smtp`) и чтение/удаление через IMAP (`mail:imap_ro` или `mail:imap_full`). Официальная справка указывает IMAP `imap.yandex.com:993` и SMTP `smtp.yandex.com:465`.
- **REST API Яндекс Почты.** Позволяет работать с папками, письмами и цепочками, читать содержимое, помечать, перемещать и удалять письма. По текущей документации доступ к API ограничен пользователями с тарифом Яндекс 360.

Источники:
- https://yandex.ru/dev/yandex-360/mail/ru/
- https://yandex.ru/support/yandex-360/business/mail/ru/web/security/oauth
- https://yandex.ru/dev/yandex-360/mcp/ru/mail

## 2. Пригодность для UT

Это почтовая модель, а не публичная доска:
- аккаунты отправителя и получателя необходимы;
- письмо можно обнаружить по IMAP/REST API, а не через публичный поиск по странице;
- доставка асинхронна и не гарантирует мгновенную видимость;
- REST API Яндекс Почты имеет тарифное ограничение Яндекс 360;
- IMAP/SMTP с OAuth может быть доступнее как стандартный вариант, но нужно проверить условия для обычных пользовательских аккаунтов и регистрации OAuth-приложения.

MCP-сервер Яндекс Почты не является транспортным API для приложения: текущая документация описывает поиск, чтение и управление письмами, но отправка писем через MCP не поддерживается.

## 3. План PoC

1. Проверить OAuth-регистрацию приложения и фактическую доступность нужных scope.
2. Проверить отправку SMTP и получение IMAP между двумя независимыми ящиками.
3. Сравнить IMAP IDLE и polling по T_discovery.
4. Если доступен REST API — сравнить его задержки и удобство с IMAP.
5. Измерить T_publish, T_visibility, T_discovery, T_download, T_e2e, p50/p95/p99.
6. Проверить лимиты, антиспам, квоты, удаление и восстановление после сетевого разрыва.
7. Проверить доступность сервиса в сетях с ограничениями; не делать выводов о белых списках по одному факту российского происхождения сервиса.

**Предварительный вывод:** полезный кандидат для почтового резервного транспорта, но не соответствует идеалу «публичная ссылка без регистрации». Главные вопросы — задержка доставки и доступность OAuth/API для обычных аккаунтов.
