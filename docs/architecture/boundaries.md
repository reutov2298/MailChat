# Границы ответственности компонентов

**Статус:** проект, требует детализации и утверждения.

## Матрица ответственности

| Область | MC | UT | Адаптер |
|---|---|---|---|
| Интерфейс | Владелец | Нет | Нет |
| Профили, контакты, чаты | Владелец | Не интерпретирует | Не интерпретирует |
| Содержание и версии сообщений | Владелец | Непрозрачные данные | Непрозрачные данные |
| Прикладная криптография | MC / модуль безопасности | Не меняет содержимое | Не меняет содержимое |
| Выбор транспорта | Задаёт требования | Владелец | Сообщает возможности |
| Маршрутизация | Получает результат | Владелец | Исполняет указания UT |
| Отправка через сервис | Нет | Координирует | Реализует |
| Приём из сервиса | Нет | Координирует | Реализует |
| Транспортные ошибки | Получает события | Классифицирует | Сообщает исходную ошибку |
| Статус доставки сообщения | Владелец прикладного статуса | Даёт транспортные факты | Даёт факты канала |
| Разработка адаптеров | Нет | Определяет контракт | Создаётся по контракту |
| Исследование транспортов | Нет | Использует результаты | Нет |

## Владение данными

- MC владеет данными мессенджера.
- UT владеет состоянием транспортных заданий, маршрутов и адаптеров.
- Адаптер владеет внутренним состоянием конкретной интеграции.
- UT Intelligence владеет исследовательскими материалами, заданиями, сборками и результатами испытаний.

Другие компоненты получают сведения через API или события, но не изменяют напрямую чужое внутреннее состояние.

## Запрещённые зависимости

1. Адаптер не обращается напрямую к базе данных MC.
2. Адаптер не управляет чатами, сообщениями и профилями.
3. UT не содержит бизнес-правил мессенджера.
4. MC не вызывает API транспортного сервиса в обход UT.
5. MC не зависит от внутренних классов конкретного адаптера.
6. UT не должен требовать центральный сервер для базовой работы, пока допустимые режимы связи отдельно не определены.
7. AI-агент не может обходить проверки и подписание компонентов при публикации.

Исключения оформляются отдельным архитектурным решением с обоснованием, рисками и сроком пересмотра.
